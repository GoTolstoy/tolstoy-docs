## get_brand_context

Reads the brand profile of the store connected to this workspace: name, website, description, target audience, logos, colors, fonts, social links, size guide and model sizes. The Tolstoy Agent and the storefront widgets use this profile. brandContext is null when the store has none yet. workspaceName is the name of the Tolstoy workspace this connection uses, which can differ from the brand name.

## update_media

Use this when the user wants to rename, star, credit a creator on, set an expiration date on, or tag products on a media item. Updates one media item's name, star, creator, expiration date, and product tags. Fields left out keep their current value.
The creator is a handle on TikTok or Instagram, stored without the leading @, and is the credit the Library and widgets show for that media.
The expiration date is not a label. From that day Tolstoy hides the item from the Library and from every widget filled from a Library search, so a wrong date silently removes it from the storefront, and a date already past hides it at once.
A product tag makes media shoppable: the item shows with that product, joins the product-tagged media most widgets are filled from, and can appear on the product's own page. A new tag is added beside the existing ones unless replaceExistingProductTags removes them. Product tagging belongs to the Main workspace.
Creator, expiration date and product tags belong to the user's own Library media; an AI draft (source studio) takes only name and favorite. Repeating the same call changes nothing further.

## get_template

Reads one content template: its full prompt verbatim, its output type, aspect ratio and category, its Remotion template ids, and its example media as URLs. A template is a proven recipe parameterized over its inputs, typically a model (the identity) and a product (the item featured); placeholders such as \{product_image\} stand for the subject of each run. The prompt is locked: a run passes it as written as the prompt of one generation, with the run's model and product images as its references. Where the template conflicts with the request, the user's own words come first, then the brand profile, then the template's defaults. A prompt that lays out several stages, review or approval rounds, or child chats, or a template with Remotion ids, runs in the Tolstoy platform. The example media show what the template makes; they are not references for a new run.
