## get_brand_context

Reads the brand profile of the store connected to this workspace: name, website, description, target audience, logos, colors, fonts, social links, size guide and model sizes. The Tolstoy Agent and the storefront widgets use this profile. brandContext is null when the store has none yet.

## search_products

Searches the product catalog of the store connected to this workspace. Each product carries its variants, with the externalProductId and externalVariantId the store's own platform uses. A catalog search pages with nextCursor. collectionId lists one Shopify collection, and bestSelling ranks the catalog by recorded sales; neither takes searchTerm, filters or cursor. A store with no recorded sales has no best sellers.

## get_media

Each item has its status, its MediaDB file with URLs and renditions, its tagged products and playlists for this store, its creator and expiration date, and originalUrl, the stored source file, when that file can be served. ## search_fashion_models

Lists the workspace's saved models, in name order: reusable people with reference images, identified by id (the aiModelId), plus Tolstoy's default models (isDefault). A model is ready, or still generating its images. Each has its name, description, gender, age group, measurements, a previewUrl, and its reference images as full-size URLs (media[].mediaReference), each marked with the view it shows (variationType: main, pose or environment). Names can repeat.

## get_template

Reads one content template: its full prompt verbatim, its output type, aspect ratio and category, its Remotion template ids, and its example media as URLs. A template is a proven recipe parameterized over its inputs, typically a model (the identity) and a product (the item featured); placeholders such as \{product_image\} stand for the subject of each run. The prompt is locked: a run passes it as written as the prompt of one generation, with the run's model and product images as its references. Where the template conflicts with the request, the user's own words come first, then the brand profile, then the template's defaults. A prompt that lays out several stages, review or approval rounds, or child chats, or a template with Remotion ids, runs in the Tolstoy platform. The example media show what the template makes; they are not references for a new run.
