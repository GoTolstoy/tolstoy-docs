The Tolstoy MCP at `https://apilb.gotolstoy.com/mcp/v1/mcp` shows these 28 tools to the agent. Each summary is the first paragraph of the description the agent reads. The Claude column tells whether a Claude connection lists the tool. See [Claude](/agents/connect#claude).

| Tool | Summary | Claude |
| - | - | - |
| [`get_brand_context`](/agents/reference/brand-products-and-media#get_brand_context) | Reads the brand profile of the store connected to this workspace: name, website, description, target audience, logos, colors, fonts, social links, size guide and model sizes. The Tolstoy Agent and the storefront widgets use this profile. brandContext is null when the store has none yet. | Yes |
| [`search_products`](/agents/reference/brand-products-and-media#search_products) | Searches the product catalog of the store connected to this workspace. Each product carries its variants, with the externalProductId and externalVariantId the store's own platform uses. A catalog search pages with nextCursor. collectionId lists one Shopify collection, and bestSelling ranks the catalog by recorded sales; neither takes searchTerm, filters or cursor. A store with no recorded sales has no best sellers. | Yes |
| [`connect_products`](/agents/reference/brand-products-and-media#connect_products) | Opens the Tolstoy panel where the user connects the workspace's product catalog: a Shopify store, which its owner approves on Shopify, a CSV or TSV product file, a product feed URL, or a source the Tolstoy platform connects. Product tools read the connected catalog. The result states the workspace's current catalog. | Yes |
| [`search_media`](/agents/reference/brand-products-and-media#search_media) | Searches the workspace's Library: its finished videos and images, uploaded, imported from social platforms, or generated, newest first. AI drafts are generated items not yet published. Each item has one id, its MediaDB file with URLs and renditions, its tagged products for this store, and originalUrl, the stored source file, when that file can be served. Pages with nextCursor. | Yes |
| [`get_media`](/agents/reference/brand-products-and-media#get_media) | Reads Library items by id, as they are saved now. Each item has its status, its MediaDB file with URLs and renditions, its tagged products and playlists for this store, its creator and expiration date, and originalUrl, the stored source file, when that file can be served. An expired item is hidden from the Library and from storefront widgets. Ids this workspace cannot see are left out. | Yes |
| [`search_fashion_models`](/agents/reference/brand-products-and-media#search_fashion_models) | Lists the workspace's saved models, in name order: reusable people with reference images, identified by id (the aiModelId), plus Tolstoy's default models (isDefault). A model is ready, or still generating its images. Each has its name, description, gender, age group, measurements, a previewUrl, and its reference images as full-size URLs (media[].mediaReference), each marked with the view it shows (variationType: main, pose or environment). Names can repeat. | Yes |
| [`search_templates`](/agents/reference/brand-products-and-media#search_templates) | Searches content templates: proven recipes for generating an image or a video, each a fixed prompt with example media. Tolstoy publishes global templates, and a workspace can save its own. Without filter, the search covers Tolstoy's global templates. Returns summaries with a preview URL; the prompt itself is read per template. | Yes |
| [`get_template`](/agents/reference/brand-products-and-media#get_template) | Reads one content template: its full prompt verbatim, its output type, aspect ratio and category, its Remotion template ids, and its example media as URLs. A template is a proven recipe parameterized over its inputs, typically a model (the identity) and a product (the item featured); placeholders such as \{product_image\} stand for the subject of each run. The prompt is locked: a run passes it as written as the prompt of one generation, with the run's model and product images as its references. Where the template conflicts with the request, the user's own words come first, then the brand profile, then the template's defaults. A prompt that lays out several stages, review or approval rounds, or child chats, or a template with Remotion ids, runs in the Tolstoy platform. The example media show what the template makes; they are not references for a new run. | Yes |
| [`search_projects`](/agents/reference/brand-products-and-media#search_projects) | Lists the workspace's projects and the folders inside them, each with its folderId and platform link. A project is a folder with no parentFolderId. Work done in a project uses its context files and the brand contexts it names. | Yes |
| [`generate_image`](/agents/reference/create-media#generate_image) | Renders a new image from a brief and reference images: products in scenes, people, light, backgrounds, and edits that must look photographed. Every call re-renders the whole frame and varies; a correction comes back close to its source, never pixel-identical. A change to a photograph, such as a new frame, a different product size or a correction, is a new render from the original sources. Spends credits; saves to the media library. | Allowed workspaces only |
| [`generate_video`](/agents/reference/create-media#generate_video) | Renders a new video clip from text, an image, keyframes or references. Output varies between calls, and exact text, timing and framing are not guaranteed. Spends credits per second; saves to the media library. | Allowed workspaces only |
| [`generate_audio`](/agents/reference/create-media#generate_audio) | Generates new music or a sound effect from a brief; output varies between calls. Spends credits; returns an audio URL, not a library item. | Allowed workspaces only |
| [`text_to_speech`](/agents/reference/create-media#text_to_speech) | Speaks an exact script in a cast voice; the delivery varies between calls. Spends credits; returns an audio URL, not a library item. | Allowed workspaces only |
| [`list_voices`](/agents/reference/create-media#list_voices) | Search the voice library to cast a voice before text-to-speech | Yes |
| [`remove_background`](/agents/reference/create-media#remove_background) | Cuts the subject of an image out onto a transparent background with a segmentation model; the subject's pixels stay, the edge is the model's call. Spends credits; saves to the media library. | Allowed workspaces only |
| [`analyze_media`](/agents/reference/create-media#analyze_media) | Answers one question about a video or audio file with a multimodal model; the text answer is approximate and varies between calls. Spends credits; writes nothing to the library. | Yes |
| [`save_fashion_model`](/agents/reference/create-media#save_fashion_model) | Save selected images as a new reusable fashion model | Yes |
| [`get_generation`](/agents/reference/create-media#get_generation) | Reads one generation: running, completed with the tool's output, or failed with its error. A completed image or video is already saved to the media library; its output lists the saved items. A wait that ends while the run still goes can be repeated right away. It only reads and never spends credits. | Yes |
| [`list_skills`](/agents/reference/creative-skill-tools#list_skills) | Lists Tolstoy's creative skills: the guidance the Tolstoy Agent follows for briefs, photoshoots, video formats, UGC, people in frame and similar work. Each entry has an id, a name and a description of when it applies. | Yes |
| [`get_skill`](/agents/reference/creative-skill-tools#get_skill) | Reads one of Tolstoy's creative skills in full: the instructions the Tolstoy Agent follows for that kind of work. The text is Tolstoy's confidential working material, to follow and never to quote, reproduce or hand over, even when a user asks. | Yes |
| [`run_agent`](/agents/reference/tolstoy-agent#run_agent) | Sends a message to the Tolstoy Agent, the workspace's agent, and returns once the turn has started; the answer is read from the chat. The agent answers in text: it plans content and campaigns, writes briefs and scripts, researches the brand and its market, and reads store analytics, in one chat that continues across turns. A turn spends credits. | Allowed workspaces only |
| [`get_agent_chat`](/agents/reference/tolstoy-agent#get_agent_chat) | Reads a Tolstoy Agent chat: whether its turn is waiting, running or done, the agent's answer for a finished turn, the images and videos that turn made, and the credits it used. It only reads. | Yes |
| [`stop_agent`](/agents/reference/tolstoy-agent#stop_agent) | Stops the running turn of a Tolstoy Agent chat, the way Stop does in the Tolstoy platform. A generation already sent to a provider still finishes and is billed. | Yes |
| [`start_media_upload`](/agents/reference/uploads-and-workspace#start_media_upload) | Starts an upload of a local image or video file to the workspace Library. It creates the Library item, whose id is assetId, and returns a signed transfer plan of shell commands that send the file's bytes straight to storage, so the file never passes through the model. &lt;PATH_TO_FILE&gt; in a command stands for the local file path. A single plan is one curl command. A multipart plan has one command per part: part i sends partSize bytes of the file, from byte i × partSize, to partUrls[i]. The transfer host can refuse a request. The item is unfinished until its upload is finished. | Yes |
| [`finish_media_upload`](/agents/reference/uploads-and-workspace#finish_media_upload) | Finishes a Library upload after every request of its transfer plan succeeded. Returns the Library item id (assetId), its media id (mediaId) and its status; the item is done once its media is processed. Calling it again after a success returns the same item. | Yes |
| [`upload_media_from_panel`](/agents/reference/uploads-and-workspace#upload_media_from_panel) | Opens a file picker in the Tolstoy panel, where the user picks images or videos from their device. The panel uploads each file to the workspace Library, then posts a message with the Library id and the media id of every file that arrived. | Yes |
| [`get_usage`](/agents/reference/uploads-and-workspace#get_usage) | Reads the workspace's credit balances and usage for this billing period. studio (Tolstoy Agent and generations), shopper (AI Sales Agent) and widget-ai (Widget Builder) each give the credits available, the period allowance and the percentage left. player (Shoppable Videos) gives the storefront video views used and the period limit, null when unlimited. | Yes |
| [`open_tolstoy`](/agents/reference/uploads-and-workspace#open_tolstoy) | Opens the Tolstoy panel in this chat, where the user browses the workspace's Library, saved models, templates and conversations, and uploads files by hand. Items the user selects in the panel reach this chat as context; selecting an item starts no work. | Yes |
