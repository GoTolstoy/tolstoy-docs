### ai-widgets search-chats

Semantic search over prior chats and their images and assets. The CLI inherits the current chat team; without an explicit team or inherited context, it searches the teams available to the caller. Use it whenever the user refers to an earlier conversation, decision, draft, brief, headline, file, image or asset. Results carry chat IDs for read-chat --chat-ids.

```text
USAGE:  tolstoy ai-widgets search-chats [flags]

FLAGS:
  --team-id       Search this team only. Null selects Main; omitted searches the teams available to the caller.
  --query         Natural language description of the prior conversation or image you are trying to recall (required)
  --title         Optional filter. Only search the chats whose current name contains all of these words.
  --source-types  Optional filter. Defaults to both chat_turn (conversation) and chat_image (generated/uploaded images). (json)
  --max-results   Maximum number of results (default 6, max 12) (number, default: 6)
  --timeframe     How to weight recency. 'recent' (default) biases toward newer chats among comparably-relevant results. Use 'any' only when the user wants the FIRST/oldest occurrence or the whole history regardless of date (e.g. 'the first time we talked about…', 'way back when'). (values: recent, any, default: "recent")
  --after         Optional ISO date/datetime. Only return chat content created on or after this. Set it when the user names the start of a period — resolve relative dates ("since March", "this week") to an absolute date using today's date.
  --before        Optional ISO date/datetime. Only return chat content created on or before this. Use with/instead of `after` for a bounded window ("in March", "last spring", "yesterday").

SCHEMAS (TypeScript):
  --source-types
  type sourceTypes = ("chat_turn" | "chat_image")[];
```
