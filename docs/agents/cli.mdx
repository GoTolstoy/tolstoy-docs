The Tolstoy CLI is the `@tolstoy-ai/cli` package on npm. It gives you your products, brand context, media library, models, AI widgets, Meta ads, and more from the command line.

The CLI is optional. The [Tolstoy MCP](/agents/connect) carries the core tools for an AI agent. Use the CLI when you work from a terminal or a script, or when your agent needs a tool that the MCP does not have. [CLI commands](/agents/reference/cli-commands) lists every command and its flags.

## Install and sign in

The CLI works on every Tolstoy plan, the free plan included. Each command still checks the features and credits of your plan.

```bash
npm install -g @tolstoy-ai/cli
tolstoy auth signup   # no Tolstoy account yet
tolstoy auth login    # you already have an account
```

To run the CLI without installing it, use `npx @tolstoy-ai/cli` in place of `tolstoy`.

Both commands sign in through the browser, and print the link in case the browser does not open:

- `tolstoy auth signup` opens the Tolstoy sign-up page. Sign up with Google, or with an email address and a password and the 6-digit code that Tolstoy sends to that address. The browser then goes to the CLI sign-in page.
- `tolstoy auth login` opens the CLI sign-in page. If you are signed out of Tolstoy, the browser shows the sign-up page first, with a link to sign in.

On the CLI sign-in page, check the workspace and click **Sign in**. The CLI saves a new API key for that workspace and a default store. The key lasts 90 days, and **Settings** → **API, MCP & CLI** → **API** lists it. `tolstoy auth logout` revokes it.

On a machine without a browser, run `tolstoy auth login --no-browser`, open the link on another device, and paste the code that the page shows into the terminal.

<Warning>
  A key acts as the person who created it, and it can get to all stores in the workspace. Keep it secret, as you keep a password.
</Warning>

## Use an API key in a script or CI

<Steps>
  <Step title="Open the API keys page">
    In Tolstoy, go to **Settings** → **API, MCP & CLI** → **API**.
  </Step>
  <Step title="Create a key">
    Click **Create API Key**. Give the key a name, for example "CI pipeline", and select when it expires.
  </Step>
  <Step title="Copy the key">
    Copy the key immediately. Tolstoy shows it only one time.
  </Step>
</Steps>

Set the `TOLSTOY_API_KEY` environment variable to the key, or add `--api-key <key>` to a command. To save the key on your machine, run `tolstoy auth login <api-key>`.

## Run commands

A command has the form `tolstoy <service> <command> [flags]`. A command that reads or changes one store needs `--app-url`. `tolstoy stores list` shows the stores that your key can use; give one of its `appUrl` values as `<store>`:

```bash
tolstoy stores list --json
tolstoy brand get-brand-context --app-url <store>
tolstoy products search-products --app-url <store> --json
```

To see all services, run `tolstoy --help`. To see the commands of a service, run `tolstoy <service> --help`. To see the flags of a command, run `tolstoy <service> <command> --help`.

| Flag | What it does |
| - | - |
| `--json` | Writes raw JSON. Without it, the output is formatted for reading. |
| `--dry-run` | Shows the HTTP request, and does not send it. |
| `--verbose` | Shows the request and response headers. |
| `--api-key <key>` | Uses this key for the command. |

| Command | What it does |
| - | - |
| `tolstoy auth status` | Checks the saved sign-in against the Tolstoy API, and shows the account, the workspace and the default store. |
| `tolstoy auth logout` | Revokes the key that `tolstoy auth login` or `tolstoy auth signup` created, and clears the saved settings. A key that you pasted is not revoked. |

## Use it with an AI coding agent

The CLI includes skills that teach an AI coding agent how to use it:

```bash
tolstoy skills list
tolstoy skills add tolstoy-products --provider claude
```

The `--provider` flag accepts `claude`, `opencode` or `agents`. The command installs the skill into the current project. To install it for all your projects, add `-g`.
